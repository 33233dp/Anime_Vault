# Anime Vault

Anime Vault 是一个面向个人使用的本地番剧观看管理网页。它适合把分散在不同网站或平台的番剧入口整理成一个统一的海报墙，并为每部番剧保存播放地址、剧集跳转规则和上一次播放记录。

项目使用 Python 标准库实现后端服务，不依赖第三方 Python 包；前端使用原生 HTML、CSS 和 JavaScript；数据持久化使用 SQLite。

> 说明：项目只负责番剧资料展示、播放地址保存、URL 拼接和浏览器跳转，不提供任何视频网站破解、解析或绕过权限的功能。

## 主要功能

- 首页海报墙浏览番剧条目
- 标题、副标题、关键词即时搜索筛选
- 番剧详情页展示海报、横版剧照、简介、演员、关键词和资料来源
- 新增番剧资料
- 编辑已有番剧资料
- 上传海报和详情页剧照，支持拖拽选择和本地预览
- 保存每部番剧的独立播放地址
- 配置剧集 URL 拼接规则
- 上传 `.m3u8` 播放列表并自动生成剧集
- 点击剧集后跳转到拼接后的播放地址
- 记录并高亮上一次播放的集数
- 首页设置个人访问密码，后续访问需要解锁，无需注册帐号
- 启动时自动创建和迁移 SQLite 数据库字段

## 适用场景

- 想把常看的番剧整理成一个本地网页入口
- 想为每部番剧保存自己的播放链接
- 想按固定 URL 规则快速跳转不同剧集
- 想记录最近看到哪一集
- 想在树莓派、个人电脑或局域网内长期自用

## 技术结构

- 后端：Python 3 标准库
- Web 服务：`http.server.ThreadingHTTPServer`
- 数据库：SQLite
- 前端：原生 `HTML + CSS + JavaScript`
- 模板：简单字符串占位符替换

## 核心文件职责

- `app.py`：极薄启动入口，保留 `python3 app.py` 的运行方式。
- `anime_vault/cli.py`：解析命令行参数，初始化数据库，启动 HTTP 服务。
- `anime_vault/config.py`：集中定义项目路径、数据库路径、模板路径和图片目录。
- `anime_vault/server.py`：处理认证、路由、表单、上传、重定向和静态文件服务。
- `anime_vault/repository.py`：创建和迁移数据库表，读写番剧数据和访问密码哈希。
- `anime_vault/renderers.py`：加载模板、渲染 HTML 片段、生成剧集 URL。
- `anime_vault/playlists.py`：校验并解析用户上传的 M3U8 播放列表。
- `anime_vault/seed.py`：内置初始番剧资料。
- `static/app.js`：首页搜索、播放地址编辑、剧集配置展开、上传预览。
- `static/styles.css`：全站视觉样式和响应式布局。
- `templates/auth.html`：设置密码和输入密码的认证页面。

## 运行方式

在项目根目录执行：

```bash
python3 app.py
```

默认监听：

```text
0.0.0.0:8000
```

本机可访问 `http://127.0.0.1:8000`，同一局域网的设备可访问 `http://运行设备IP:8000`。

指定端口：

```bash
python3 app.py --port 8080
```

如果只允许本机访问：

```bash
python3 app.py --host 127.0.0.1 --port 8000
```

只初始化数据库，不启动服务：

```bash
python3 app.py --init-db
```

完整运行说明见 [docs/运行教程文档.md](docs/运行教程文档.md)。

## 数据持久化

数据库文件位于：

```text
data/anime.db
```

数据库会保存：

- 番剧 slug、标题、副标题、发行信息和制作公司
- 简介、演员、关键词、资料来源
- 海报路径和详情页剧照路径
- 播放地址
- 资源类型、M3U8 文件名和解析后的分集播放信息
- 剧集总数
- 剧集 URL 拼接参数
- 集数查询偏移
- 上一次播放的集数
- 访问密码的随机盐、哈希和会话签名密钥（不会保存明文密码）

启动时会自动执行数据库初始化和字段补齐。内置种子数据会更新基础资料字段，但不会覆盖用户保存的播放地址、剧集配置和播放记录。

## 隐私保护

首次打开首页时，点击“添加密码”即可设置访问密码。密码至少需要 6 个字符，设置完成后当前浏览器会话会自动解锁。

之后访问网站时，如果没有有效的解锁会话，首页会显示密码输入页。输入正确密码后才能访问番剧详情、海报、剧照、视频、本地播放和编辑接口。首页中的“修改密码”可以更换密码，“锁定”可以立即结束当前会话。

项目不提供帐号注册、找回密码或多用户权限。密码只以 PBKDF2 哈希形式写入 `data/anime.db`，浏览器使用带签名的 HttpOnly 会话 Cookie 保持解锁状态。迁移或备份时必须连同数据库一起保留，否则密码配置也会丢失。

如果忘记密码，只能先备份数据库，再删除 `privacy_settings` 表中的唯一配置记录，然后重新启动服务并设置新密码。这个操作不会删除番剧资料，但建议先保留原数据库备份。

## 剧集 URL 规则

详情页的“剧集 -> 配置”会保存以下字段：

- `总集数`
- `根域名`
- `路由`
- `查询参数前缀`
- `集数查询偏移`
- `其他`

点击第 `N` 集时，最终 URL 按下面规则拼接：

```text
根域名 + 路由 + 查询参数前缀 + (集数查询偏移 + N - 1) + 其他
```

示例：

```text
总集数 = 25
根域名 = https://example.com
路由 = /watch
查询参数前缀 = ?ep=
集数查询偏移 = 0
其他 = &from=anime
```

点击第 1 集会跳转到：

```text
https://example.com/watch?ep=0&from=anime
```

## 新增和编辑番剧

首页点击“新增番剧”可打开新增页。详情页点击“编辑资料”可修改已有条目。

新增和编辑页支持：

- 手动填写项目内图片路径，例如 `poster/example.webp`
- 从当前设备选择图片上传
- 拖拽图片到上传区域
- 上传前在浏览器中预览图片
- 选择“播放链接 / 路由”并沿用原有播放地址和 URL 拼接配置
- 选择“M3U8 文件”上传 UTF-8 编码的 `.m3u8` 播放列表，自动解析每集标题和 HTTP/HTTPS 播放地址

上传后的海报会保存到 `poster/`，剧照会保存到 `Stills/`。文件名会根据 slug 自动生成。

## 安全边界

这是个人本地工具，不是面向公网的生产服务。

需要注意：

- 默认监听 `0.0.0.0`，同一局域网的设备可以通过运行设备的 IP 地址访问。
- 仅在受信任的局域网中运行；如需限制为本机访问，使用 `--host 127.0.0.1`。
- 访问密码是个人站点级别的保护，不是帐号系统，也不提供多用户权限管理。
- 设置密码后，番剧页面和媒体资源需要解锁；用于加载界面的 `static/styles.css` 和 `static/app.js` 仍可公开读取。
- 当前服务使用普通 HTTP，不提供 HTTPS 加密。通过不受信任的网络访问时，密码可能被网络监听，建议使用 SSH 隧道、VPN 或带 HTTPS 和认证的反向代理。
- 不建议直接暴露到公网。
- 如果必须远程访问，建议通过 SSH 隧道、VPN 或反向代理加认证。
