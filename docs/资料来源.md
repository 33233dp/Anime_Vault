# 资料来源

本文说明项目内置番剧资料的来源范围，以及哪些内容需要用户自行配置。

## 来源范围

简介与主要演员信息基于官方站点、公开百科资料和公开条目整理。页面中的“关键词”为依据剧情设定与题材标签做出的归纳总结，不是原站点原文。

项目中的播放地址、剧集地址规则、集数查询偏移和其他播放参数不来自以下资料来源，需要由用户自行配置。

## 用户自定义数据

以下数据由用户通过页面或数据库自行维护：

- 播放地址
- 剧集根域名
- 剧集路由
- 查询参数前缀
- 集数查询偏移
- 其他 URL 参数
- 上一次播放集数
- 用户新增番剧资料
- 用户上传的海报和剧照

## 更新资料的方式

可以通过两种方式更新资料：

1. 在详情页点击“编辑资料”，通过网页表单修改。
2. 修改 `anime_vault/seed.py` 中的内置种子资料，然后执行 `python3 app.py --init-db`。

如果只是个人使用，推荐优先使用网页编辑功能；如果要维护默认内置资料，再修改 `seed.py`。
