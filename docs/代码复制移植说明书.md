# 代码复制移植说明书

本文说明如何把 Anime Vault 复制到另一台机器、如何保留数据、如何备份，以及迁移后需要检查的事项。

## 最小复制清单

建议复制整个项目目录。最少需要包含：

```text
app.py
anime_vault/
templates/
static/
poster/
Stills/
data/anime.db
docs/
README.md
```

如果只复制代码而不复制 `data/anime.db`，应用仍然可以启动，但播放地址、剧集配置、上一次播放记录和手动新增条目可能丢失。

## 推荐迁移步骤

1. 在旧机器停止正在运行的 Anime Vault 服务。
2. 复制整个 `Anime/` 项目目录到新机器。
3. 确认新机器安装了 Python 3.10 或更高版本。
4. 进入项目目录。
5. 执行 `python3 app.py --init-db`，让程序检查并补齐数据库字段。
6. 执行 `python3 app.py` 启动服务。
7. 浏览器访问 `http://127.0.0.1:8000`。

## 保留现有数据

必须保留：

```text
data/anime.db
```

这个文件保存：

- 新增番剧
- 编辑后的番剧资料
- 播放地址
- 剧集配置
- 上一次播放集数

如果上传过图片，也必须保留：

```text
poster/
Stills/
```

否则数据库里保存的图片路径可能找不到对应文件。

## 只迁移代码，不迁移数据

如果你只想得到一份干净的新环境，可以不复制 `data/anime.db`。首次启动时程序会根据 `anime_vault/seed.py` 重新创建数据库。

注意：这会丢失旧数据库中的用户数据。

## 更新内置番剧资料

内置种子资料位于：

```text
anime_vault/seed.py
```

修改后执行：

```bash
python3 app.py --init-db
```

已有 slug 对应的基础资料会更新，但播放地址、剧集配置和播放记录不会被种子数据覆盖。

## 替换或新增图片资源

方式一：通过网页上传。

- 首页点击“新增番剧”或详情页点击“编辑资料”
- 选择或拖拽海报、剧照
- 保存后程序自动写入 `poster/` 和 `Stills/`

方式二：手动复制图片。

- 海报放入 `poster/`
- 剧照放入 `Stills/`
- 在新增或编辑页面填写相对路径，例如 `poster/example.webp`

## 修改端口或监听地址

只改端口：

```bash
python3 app.py --port 9000
```

默认允许局域网访问：

```bash
python3 app.py --port 8000
```

局域网访问示例：

```text
http://192.168.0.111:8000
```

## 备份建议

日常备份至少包含：

```text
data/anime.db
poster/
Stills/
```

完整备份建议直接备份整个 `Anime/` 目录。

可以使用类似命令：

```bash
cp -r Anime Anime_backup_$(date +%Y%m%d_%H%M%S)
```

## 安全注意事项

Anime Vault 是个人本地工具，不带登录认证。

- 默认监听 `0.0.0.0`，局域网设备可通过运行设备的 IP 地址访问。
- 如需限制为本机访问，使用 `--host 127.0.0.1`。
- 不建议把服务直接暴露到公网。
- 如需远程访问，建议使用 SSH 隧道、VPN 或带认证的反向代理。
- 因为服务继承 `SimpleHTTPRequestHandler`，项目目录中的静态文件可能被直接访问。

## 迁移后检查清单

- 首页能打开
- 海报能显示
- 详情页背景图能显示
- 新增番剧能保存
- 编辑资料能保存
- 播放地址能保存
- 剧集配置能保存
- 点击剧集能跳转
- 上一次播放记录能更新
