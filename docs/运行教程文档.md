# 运行教程文档

本文说明 Anime Vault 的运行环境、启动方式、页面使用方法和常见问题。

## 环境要求

- Python：3.10 及以上
- 浏览器：Chrome、Edge、Firefox 或 Safari 的较新版本
- 操作系统：Linux、Windows、macOS 或树莓派系统

项目后端只使用 Python 标准库，不需要安装第三方 Python 包。

## 启动服务

进入项目根目录：

```bash
cd ~/code/Anime
```

启动：

```bash
python3 app.py
```

默认监听：

```text
0.0.0.0:8000
```

本机访问 `http://127.0.0.1:8000`，同一局域网内的其他设备访问 `http://运行设备IP:8000`。

## 指定端口

```bash
python3 app.py --port 8080
```

访问：

```text
http://运行设备IP:8080
```

## 局域网访问

直接运行 `python3 app.py` 时已经监听 `0.0.0.0`，无需添加额外参数。然后在其他设备浏览器访问：

```text
http://树莓派IP:8000
```

示例：

```text
http://192.0.2.10:8000
```

注意：项目没有登录认证，不建议暴露到公网。

## 只初始化数据库

```bash
python3 app.py --init-db
```

该命令会创建 `data/anime.db`、创建或迁移 `anime` 表，并写入或更新内置种子资料。它不会启动 Web 服务。

## 首次运行会发生什么

首次启动时，项目会自动创建 `data/` 目录、创建 `data/anime.db`、创建 `anime` 表，并写入 `anime_vault/seed.py` 中的内置番剧资料。

之后再次启动时，会继续使用同一个数据库。

## 首页使用

打开首页后可以看到番剧海报墙。

首页支持：

- 查看当前馆藏数量
- 点击海报进入详情页
- 在搜索框输入标题、题材或关键词即时筛选
- 点击“新增番剧”打开新增页面

## 详情页使用

详情页展示海报、横版剧照背景、标题、副标题、发行信息、制作公司、简介、播放地址、剧集演员、关键词、资料来源、剧集列表和上一次播放记录。

点击“返回海报墙”回到首页。点击“编辑资料”进入编辑页面。

## 播放地址

详情页的播放地址默认是只读状态。

- 点击播放地址输入框：如果地址非空，会在新标签页打开该地址。
- 点击“编辑地址”：输入框变为可编辑。
- 修改后点击“保存地址”：写入 SQLite 数据库。

## 剧集配置

详情页底部有“剧集”面板。点击“配置”后可以编辑：

- `总集数`：控制生成多少个剧集按钮。
- `根域名`：例如 `https://example.com`
- `路由`：例如 `/watch`
- `查询参数前缀`：例如 `?ep=`
- `集数查询偏移`：控制真正拼接到 URL 中的起始编号。
- `其他`：补充额外参数，例如 `&source=anime`

保存后页面会回到详情页并重新生成剧集按钮。

## 剧集 URL 拼接规则

点击第 `N` 集时，项目会按下面规则拼接 URL：

```text
根域名 + 路由 + 查询参数前缀 + (集数查询偏移 + N - 1) + 其他
```

示例：

```text
总集数 = 25
根域名 = https://example.com
路由 = /watch
查询参数前缀 = ?ep=
集数查询偏移 = 0
其他 = &from=anime
```

点击第 1 集：

```text
https://example.com/watch?ep=0&from=anime
```

点击第 25 集：

```text
https://example.com/watch?ep=24&from=anime
```

点击某一集后，项目会记录该集为“上一次播放”，并在剧集列表中高亮。

## 新增番剧

首页点击“新增番剧”进入新增页面。

至少需要填写：

- slug
- 番剧名
- 海报路径或上传海报
- 剧照路径或上传剧照

其他字段可以按需要填写：副标题、发行信息、制作公司、资源、简介、剧集演员、关键词和资料来源。

“资源”提供两种方式：

- “播放链接 / 路由”：保留原有的播放地址、总集数和 URL 拼接配置。
- “M3U8 文件”：上传 UTF-8 编码的 `.m3u8` 文件，系统会读取 `#EXTINF` 标题和后续 HTTP/HTTPS 播放地址，并按顺序自动生成剧集。

提交成功后会跳转到新番剧详情页。

## 编辑番剧

详情页点击“编辑资料”进入编辑页面。

编辑页和新增页共用同一个表单，但编辑模式下 slug 不允许修改。保存后会更新数据库中的对应条目。

如果重新上传海报或剧照，文件会覆盖同 slug 对应的上传图片文件。

## 图片上传

海报和剧照都支持手动填写项目内相对路径、点击上传区域选择本地图片、拖拽图片到上传区域和浏览器内预览。

支持格式：

```text
JPG, JPEG, PNG, GIF, WEBP, BMP, SVG, AVIF
```

上传后的海报保存到 `poster/`，上传后的剧照保存到 `Stills/`。

## 数据备份

最重要的文件是：

```text
data/anime.db
```

它保存播放地址、剧集配置和播放记录。如果新增或上传了图片，也要备份 `poster/` 和 `Stills/`。

## 常见问题

### 浏览器无法打开页面

- 确认终端显示了 `Serving on http://...`
- 确认访问地址和端口正确
- 如果从其他设备访问，确认没有显式使用 `--host 127.0.0.1`
- 检查防火墙是否阻止端口

### 图片不显示

- 确认 `poster/` 和 `Stills/` 目录存在
- 确认数据库中的图片路径是相对项目根目录的路径
- 确认图片文件名没有被删除或改名

### 新增番剧提示 slug 已存在

slug 是番剧的唯一标识。换一个未使用过的 slug。

### 点剧集没有正常跳转

- 确认 `总集数` 大于 0
- 确认 `根域名` 已填写
- 检查 `路由`、`查询参数前缀`、`集数查询偏移`、`其他` 拼接后是否是目标网站需要的格式

### 保存后数据没有变化

- 确认表单提交后页面有刷新或跳转
- 确认 `data/anime.db` 可写
- 重新启动服务后再检查

### 需要重置数据库

先备份当前数据库：

```bash
cp data/anime.db data/anime.db.bak
```

如果确定要重新生成数据库，可以删除 `data/anime.db` 后重新启动服务。删除会丢失播放地址、剧集配置和播放记录。
