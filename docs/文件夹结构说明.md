## 根目录

- `app.py`
  项目启动入口。文件本身只导入 `anime_vault.main` 并执行，用于保留简单的 `python3 app.py` 运行方式。

- `README.md`
  项目总说明，包括功能概览、运行方式、数据持久化、剧集 URL 规则和安全边界。

## `anime_vault/`

后端 Python 包，包含启动逻辑、HTTP 路由、数据访问和页面渲染。

- `__init__.py`
  暴露 `main`，让 `app.py` 可以通过 `from anime_vault import main` 启动应用。

- `cli.py`
  命令行入口。负责解析 `--host`、`--port`、`--init-db`。启动时会先调用 `ensure_database()`，再根据参数决定是否启动 HTTP 服务。

- `config.py`
  集中定义项目根目录、数据库路径、模板路径、海报目录和剧照目录。

- `repository.py`
  SQLite 数据访问层。负责建表、字段迁移、写入种子资料、查询、创建、更新、保存播放地址、保存剧集配置、记录上一次播放集数，以及保存和验证访问密码哈希。

- `renderers.py`
  页面渲染辅助模块。负责读取模板、替换占位符、生成 HTML 片段，并根据配置拼接剧集播放 URL。

- `playlists.py`
  M3U8 上传解析模块。负责文件格式、编码和播放地址校验，并生成分集标题与链接。

- `seed.py`
  内置番剧基础资料。启动初始化数据库时会将这里的内容写入数据库。

- `server.py`
  HTTP 请求处理器。负责访问密码设置和解锁、首页、新增页、详情页、编辑页、表单提交、剧集跳转、静态文件服务和图片上传保存。

## `data/`

- `anime.db`
  SQLite 数据库文件。保存番剧资料、图片路径、播放地址、剧集配置、播放记录以及访问密码哈希和会话签名密钥。

建议定期备份这个文件。迁移到新机器时，如果想保留播放地址和播放记录，应一起复制 `data/anime.db`。

## `poster/`

首页海报墙使用的竖版海报目录。新增或编辑番剧时，如果上传海报，后端会将文件保存到这里，并把相对路径写入数据库。

## `Stills/`

详情页使用的横版剧照或背景图目录。新增或编辑番剧时，如果上传剧照，后端会将文件保存到这里，并把相对路径写入数据库。

## `static/`

- `app.js`
  浏览器交互脚本。包含首页即时搜索、海报卡片预取、播放地址编辑、资源类型切换、M3U8 与图片拖拽上传、格式校验和预览。

- `styles.css`
  全站样式。包含首页、详情页、编辑页、上传组件和响应式布局。

## `tests/`

- `test_playlists.py`
  测试 M3U8 文件解析、扩展名校验和播放地址校验。

- `test_privacy.py`
  测试访问密码哈希验证，以及修改密码时会话签名密钥轮换。

## `templates/`

- `index.html`
  首页海报墙模板。

- `detail.html`
  番剧详情页模板。

- `anime_form.html`
  新增和编辑番剧共用模板。

- `auth.html`
  设置访问密码、修改密码和输入密码解锁的页面模板。

## `docs/`

- `运行教程文档.md`
  说明如何启动、访问、使用页面和排查常见问题。

- `流程图.md`
  用文本流程图描述主要功能的请求和数据流。

- `代码复制移植说明书.md`
  说明如何复制项目、保留数据库、迁移图片和部署到其他机器。

- `资料来源.md`
  说明内置番剧简介、演员和资料链接来源。

- `文件夹结构说明.md`
  当前文件，即目录结构和模块职责说明。
